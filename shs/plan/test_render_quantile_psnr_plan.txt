一、目标与解释

1. 将“0.995 灰度阈值”解释为每张渲染图像灰度分布的 0.995 分位数，
   即第 99.5 百分位数；不是固定灰度值 0.995，也不是最大灰度的 0.995 倍。
2. 在渲染完成后，从该图像的原始灰度 raw_intensity 计算阈值 t，
   用同一个比例缩放全图，使灰度 t 映射到 1，再将超过 1 的值裁减为 1。
3. 测试图像 PNG、TensorBoard 测试图像和测试 PSNR 使用同一份处理后的张量。
   测试 L1 也使用这一张量，保持同次评测输入一致。
4. 默认仅处理测试集的预测图像。GT 沿用 original_image 的现有 [0,1] 值，
   不重新归一化，不改用 anti_noise_image。
5. 本阶段只产出规划；后续实施以当前工作区代码为基础，保留已有未提交修改。

三、算法约定

输入：单张单通道声呐灰度张量 I，支持 [H,W] 或 [1,H,W]。
目前数据读取使用 convert("L")，不需要 RGB 转灰度规则。
若未来支持批量图像，应逐张独立计算阈值，不能跨图像混合统计。

预处理与正常路径：
  J = clamp(nan_to_num(I, nan=0, posinf=0, neginf=0), min=0)
  t = quantile(J.reshape(-1), 0.995, interpolation="linear")
  O = clamp(J / t, min=0, max=1)    （t > 1e-8）

具体要求：
1. 阈值在原始渲染灰度上计算，不先做最大值、逐行归一化或上限裁减。
2. 使用全图全部像素，包含零背景；不按 valid_mask、前景或非零像素筛选。
3. 所有像素使用同一个标量 t；测试时不受 normalizing_method=range 影响。
4. 采用线性插值分位数。对小图像或重复灰度，实际饱和像素比例不一定
   恰好等于 0.5%，不能把饱和比例作为算法定义。
5. 保留图像形状和设备；至少用 float32 计算分位数与除法，避免低精度
   分位数计算问题。阈值返回标量张量，不在正常路径强制转 CPU。
6. 不改变 raw_intensity，不对输入或 render_pkg 进行原地修改。

零阈值与异常输入的默认处理建议：
1. 当全图近似为零（max(J) <= 1e-8），返回全零图，避免除零及 NaN。
2. 当 t <= 1e-8 但图中存在有效正值时，退化为 max(J) 归一化并 clamp。
   例如非零像素少于约 0.5% 时，全图分位数可能为零；退化处理保留这些
   像素，避免除零。此为退化分支，需在函数说明和测试中明确。
3. 空张量或非单通道输入应明确报错，避免静默采用错误的灰度统计维度。
4. PSNR 的完全匹配、空测试集和非有限结果沿用现有状态返回约定。

五、PSNR 计算口径

对每张测试灰度图：
  G = clamp(original_image, 0, 1)
  MSE = mean((O - G)^2)             （整张图所有像素）
  PSNR = -10 * log10(MSE)           （峰值固定为 1）

测试集结果 = mean(各测试视角 PSNR)，保持当前逐图 dB 平均方式。
不先对整套图像平均 MSE 再转换为 PSNR，也不引入掩码 PSNR。
PSNR 使用归一化后的浮点 O，而非将 PNG 保存再读回后计算。
PNG 显示内容与 O 一致，但 uint8 量化会引入误差，离线重算不保证与在线
浮点 PSNR 完全相同；不为追求完全一致而改变当前指标精度。

六、验证方案

1. 算法单元验证
   - 用可手算样本验证线性插值：J=[0,1,2,100] 时 t=98.53；
     输出为 [0,1/98.53,2/98.53,1]。
   - 用含少量极亮离群点的图像确认采用分位数而非最大值。
   - 全零、恒定正值、极稀疏正值、负值和 NaN/Inf 输入结果有限且处于 [0,1]。
   - 多行亮度不同的图像使用一个分母，零背景参与分位数。
   - 非退化情况下，整体乘正数后得到相同输出；验证输入未被原地修改。
2. training_report 集成验证
   - 使用实际后处理函数，构造已知 raw_intensity 与非平凡 GT，手算 PSNR。
   - 测试函数输入不依赖原有 r_intensity，防止误接旧归一化结果。
   - 保存图像像素等于 round(O*255)，PSNR 使用浮点 O。
   - 关闭保存时 PSNR 不变；普通目录和质量目录输出字节一致，仍只渲染一次。
   - normalizing_method=all/range 对测试输出无影响；train 诊断维持原行为。
   - anti_noise_enabled=True 时仍与 original_image 比较。
   - 保留空测试集、完美预测和逐视角 PSNR 平均验证。
3. 质量记录验证
   - config.json 明确记录新协议和分位数，曲线取得新 PSNR。
   - 新协议检查点正常恢复，旧协议配置不能混入新曲线。
   - 确认后处理仍发生在评测计时区域，不计入纯训练时间。
4. 最小 GPU 验证（实施时有可用环境再执行）
   - 对同一组已知图像比较 CPU/CUDA 阈值与输出，允许合理浮点容差。
   - 用少量真实测试视角确认图像输出和 PSNR，以及两条测试调用路径。
   - 不需要为此规划启动完整训练或重复几何重建。

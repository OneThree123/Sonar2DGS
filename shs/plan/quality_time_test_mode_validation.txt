质量—训练时间测试模式实施与验证记录
日期：2026-10-05
对应规划：shs/plan/quality_time_test_mode_plan.txt

已实施：
  - 新增 --quality_time_test 和 --quality_save_test_images，默认关闭。
  - 固定 26 个累计训练时间节点，完整组结束后到达/超过即触发。
  - 保留 iteration/final，同组跨多个节点或多原因合并为一次评测、一条记录。
  - iteration/final 独立触发时覆盖节点为空；迭代结束后不补测未来节点。
  - 从数据集 dense_points3d.ply 初始化 Poisson 真值；按来源/重建配置/后端版本缓存。
  - 真值初始化完成后才启动报告总时长；真值准备不计入累计训练时间或报告总时长。
  - 单位固定为米；不需要 GT 路径或单位参数。
  - 公共 utils/gaussian_mesh.py 提取现有 GS 过滤、surfel 采样、Poisson 和点云导出。
    Scene 保存和质量评测均调用该模块，不再依赖 Git 忽略的 output/ 本地代码。
  - 预测几何实际先导出 GS、采样并做 Poisson，再对预测 mesh 表面做固定种子、
    面积加权 100000 点采样，计算其到真值三角面的单向平均距离。
  - GT 的 Open3D RaycastingScene 空间结构复用，分块查询真实点到面距离，不依赖 rtree。
  - 同组模型保存复用已生成的预测 mesh；几何失败后也不在保存时重复重建。
  - 透明度重置移到下一组组前，其耗时归下一组；v3 检查点保存 pending 状态。
    无新组可运行时不执行重置，续训组前执行一次；旧检查点不补做历史重置。
  - 每个 run 单独输出 CSV、JSONL、配置、摘要和离线 HTML；支持历史截断和恢复。
  - HTML 支持线性/对数时间轴、双图、悬停、触发原因、覆盖节点及结果表。
  - 异常/KeyboardInterrupt 收尾关闭输出，不再启动 final 或补测。
